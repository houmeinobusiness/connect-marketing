# 制作指示⑤：Tally・プライバシーポリシー実装報告

作業日：2026年10月25日（日本時間）／対象：feature/lp-v3、開始コミット b5342e8。

## 実装

- 正式Tally ID `EqkyYX` を公式のdata-tally-src／widgets/embed.js方式でインライン埋め込み。幅100%、初期高さ900px、Dynamic Height有効。
- 旧ダミーフォームは削除。Tally iframeは1つ、入力フォームの二重表示なし。
- 正式フォームへの代替リンクを常時表示。埋め込みを読み込めない場合やJavaScript無効時にもリンクを利用できる構成。
- `/privacy/` に提供原稿全文（9項目、制定日を含む）を掲載。フッター・問い合わせ欄・フォーム下部からリンク。ページ固有のtitle・description・canonical・OG URLを設定。
- ヘッダーリンクをサブページからもLPへ戻れるよう調整。FV・サービス・代表の内容・色は維持。
- Tally内部の同意文には現在リンクがない。LP側の参照リンクは実装済みだが、Tally側の設定は管理画面での作業が必要。
